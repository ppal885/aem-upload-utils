    Content packages

    Packages you built from a local folder. Download them for CRX Package Manager, or install them on an AEM server from here. They are kept for 7 days.

    Installing on AEM as a Cloud Service? Reprocess the folder afterwards.

    Cloud does not process assets that arrive in a package, so they have no renditions or Guides processing until you reprocess them.

    1. In AEM Assets, open the parent folder and select the installed folder.
    2. Click Reprocess Assets and choose Full Process.

    Prefer no extra step? Use instead: every file is processed automatically. On-premise AEM processes package content by itself.
